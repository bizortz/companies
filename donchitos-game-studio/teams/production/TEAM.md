The production department keeps the studio running smoothly. Led by the Producer, it handles release management, localization, analytics, prototyping, accessibility, live operations, and community management. (DevOps and security report through the engineering department's Technical Director — see `teams/engineering/TEAM.md` — since build infrastructure and security are engineering-quality concerns; the production department still requests release builds and security sign-off from them at each milestone.)
