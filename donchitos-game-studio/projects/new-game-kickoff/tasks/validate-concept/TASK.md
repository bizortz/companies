Run the `concept-validation` skill on the proposed concept before pillar
work begins: choose a fake-door or CPI test, set pass/fail thresholds in
advance, run it, and issue a PROCEED / RESHAPE / KILL verdict. This is the
first task in the project — a concept that fails validation should be
reshaped or killed before any pillar, systems, or prototype investment is
made. PROCEED is required before `define-game-pillars` starts.

## Deliverables
- Concept validation report (`ops/reports/validation/<date>-<concept-slug>.md`)
- PROCEED / RESHAPE / KILL verdict with evidence
- If RESHAPE: specific feedback routed back to creative-director before re-attempting

## Next Task
`define-game-pillars` (only on a PROCEED verdict)
