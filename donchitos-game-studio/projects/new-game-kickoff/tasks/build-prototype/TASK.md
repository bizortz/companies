Build a minimal, throwaway prototype that validates the core game mechanic identified in the system decomposition. Focus on answering the key design hypothesis — does the core mechanic feel good? Measure the prototype against `design/perf-budget.md` (from `set-perf-budget`) on at least the low-tier device band, not just the highest-end device available. Document findings regardless of outcome.

## Deliverables
- Playable prototype (throwaway quality)
- Findings report with hypothesis, method, results, and recommendation
- Go/no-go recommendation for production
