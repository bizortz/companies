Take a game concept from initial idea through the first three development phases — Ideation, Pre-Production, and Prototyping — resulting in a validated playable prototype ready for production.

## Task Sequence

1. `validate-concept` (market-analyst) — cheap external signal (fake-door or CPI test) before any pillar/systems/prototype investment
2. `define-game-pillars` (creative-director) — Concept Lock
3. `select-engine` (technical-director) — Pre-Production
4. `decompose-systems` (game-designer) — Pre-Production
5. `set-perf-budget` (performance-analyst) — Pre-Production, alongside 3 and 4
6. `build-prototype` (prototyper) — Prototyping / First Playable, measured against the perf budget from step 5
7. `plan-first-sprint` (producer) — after a go decision

## Milestones

1. **Concept Lock** — Concept validated (PROCEED verdict from `validate-concept`), game pillars defined, core fantasy articulated, competitive positioning mapped
2. **Pre-Production Complete** — Systems decomposed, GDDs drafted for core mechanics, architecture planned, device performance budget set
3. **First Playable** — Prototype validates the core mechanic against the performance budget, findings documented, go/no-go decision made
